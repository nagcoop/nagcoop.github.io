Classics running natively on PC

A curated list of fan-made recompilations and ports, plus the tools behind them. Every link goes to the project's official page.

⚠️ None of these projects include the game. You need the files from your own original copy. Nagcoop does not host or point to downloads of commercial games. Want to know how it works? Read the static recompilation guide on the blog.

Recompiled ports

Console games translated into native PC programs, with widescreen, high frame rates and mods.

Nintendo 64 · Windows / Linux

Zelda 64: Recompiled

Majora's Mask running natively on PC, rendered by RT64, with a mod loader. Requires the US ROM from your cartridge.

Official page ↗ Nintendo 64 · Windows / Linux

Starfox 64: Recompiled

Star Fox 64 with enhancements and extensive mod support. Sibling project of the Starship port.

Official page ↗ Xbox 360 · PC

Unleashed Recompiled

Sonic Unleashed with an unlocked frame rate and ultrawide. Requires your own game files (US or EU) dumped from your Xbox 360.

Official page ↗ PlayStation 1 · Windows / Linux / macOS

SymphonyRecomp

BlackLabelHQ's Castlevania: Symphony of the Night, in open beta, with widescreen and extras. Requires the .bin/.cue of your US disc.

Tools

For anyone who wants to understand or contribute to recompilation projects.

Recompiler · N64

N64: Recompiled

The tool that started it all: translates Nintendo 64 code into C that compiles for any platform.

GitHub ↗ Recompiler · Xbox 360

XenonRecomp

Converts Xbox 360 PowerPC code into C++. The foundation of Unleashed Recompiled, alongside XenosRecomp for shaders.

GitHub ↗ Recompiler · Arcade

MidwayRecomp

An N64Recomp fork for Midway arcade boards, home to games like CarnEvil and California Speed.
